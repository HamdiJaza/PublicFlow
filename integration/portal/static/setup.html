NVIDIA key for report preparation

If report preparation (Intake) is unavailable, save your NVIDIA API key once for this Windows account. It is encrypted locally, never shown in commands or results, and the previous encrypted copy is kept.

Saving the key starts Intake without calling any model. NVIDIA is only called when a citizen sends a report.
