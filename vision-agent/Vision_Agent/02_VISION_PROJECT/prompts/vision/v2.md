# Vision v2

**Executable prompt:** [v2.txt](v2.txt). **Role:** identify the main visible issue and give relevant evidence without guessing its cause.

**Techniques:** zero-shot, role prompting, fixed labels, structured output instructions, direct visual grounding, abstention and uncertainty guardrails. The evidence rules request one to three visible facts; background objects alone are not proof of an incident. No chain-of-thought or separate reasoning call is requested.

**Observed failures:** irrelevant uncertainty on the waste scene; missing water and uncertain road-damage claims on IMG-04. Severity values originally lacked a common rubric.

**Correction tested:** [v3](v3.md) adds three real demonstrations while keeping the system prompt identical. The first matched trial improved some details but introduced invented waste on the wet-road image and copied uncertainty wording. It was not promoted.

**Final study:** v2 and v3 both receive the separately versioned [severity addendum](severity_v1.md). Their original files stay unchanged. The comparison tests zero-shot versus these particular few-shot examples under a common rubric, not all possible few-shot designs.

**Evidence:** [original v2/v3 review](../../evaluation/vision/comparisons/20261017T104705_090963Z/review.csv), [final protocol](../../evaluation/vision/final_study/protocol.md), [results](../../evaluation/vision/final_study/metrics.json).

**Final outcome:** 11/11 validated outputs; 5/5 clear-reference categories; 3/4 severity matches; 1/2 text comparisons and 0/4 conservative abstentions. It correctly rejected the unrelated screenshot, but also returned NONE for severe blur. It falsely marked the contradictory description as matching. These small-case counts do not establish general accuracy.
