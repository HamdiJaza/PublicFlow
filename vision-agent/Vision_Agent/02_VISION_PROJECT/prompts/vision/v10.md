# Vision v10: verify the caption against the original image

**Executable prompts:** unchanged [v2.txt](v2.txt) plus [severity_v1.txt](severity_v1.txt) for the image pass; [v10_compare.txt](v10_compare.txt) for caption verification.

**Role and techniques:** prompt chaining; image-only zero-shot classification, then image-grounded caption verification with a dedicated role, explicit comparison criteria, abstention and three short contrasting text examples. The second call receives the original photograph, recorded visual notes and caption. No reasoning transcript, vote, training or new model is used.

**Failure corrected:** v9 handles vague text but falsely rejects the matching branches caption because the first pass omitted the branches. V10 explicitly treats notes as incomplete and tells the reviewer to verify the actual pixels. An omitted detail alone is not a contradiction. Unlike v7, there are no demonstration photographs or complete visual targets to copy.

**Runtime:** same first-stage output schema, caption enum schema, four-state mapping and result composition as v9. Category, severity, description, evidence and visual confidence remain the first pass's outputs. The second stage determines consistency and explains inconclusive text. Both requests and raw answers are preserved. With no text, skip comparison. This is a revised chain configuration, not an isolated prompt-wording effect.

**Evaluation:** [frozen protocol](../../evaluation/vision/image_review/protocol.md); the same six conditions, one pipeline each, six explicitly reused v6 controls. Same model digest, image bytes, severity rubric and decoding parameters. Six pipelines require eleven calls. No silent retries or generated replacement responses.

**Limits:** the known caption is included literally; these are targeted development checks. The first image pass can still underdescribe branches or produce irrelevant uncertainty. The reviewer can itself misread images. This study does not establish general category, rejection, language or severity accuracy.

**Measured outcome:** 3/6 comparison targets, 0/2 vague cases explained and 6/6 categories/severities; eleven calls across six pipelines. The reviewer returned SUPPORTED for every supplied caption, including both help requests and the explicit denial. It corrected v9's matching-text error but was not promoted.
