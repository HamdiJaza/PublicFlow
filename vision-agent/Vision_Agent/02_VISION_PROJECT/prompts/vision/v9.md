# Vision v9: image analysis followed by caption comparison

**Executable prompts:** unchanged [v2.txt](v2.txt) plus [severity_v1.txt](severity_v1.txt) for image analysis; [v9_compare.txt](v9_compare.txt) for caption comparison.

**Roles and techniques:** the first prompt describes and classifies the actual image without citizen text. The second is a text-comparison role with explicit criteria, grounding in the recorded observations, abstention rules and three short contrasting text/target examples. Passing the first response to the second prompt is prompt chaining. No chain-of-thought transcript, voting or model training is used.

**Observed failures:** v6 explicit rules scored 3/6 on comparison; v7 multimodal examples scored 5/6 but confused the vague local caption with contradiction and copied visual targets; v8's inline text examples still accepted both vague requests. Their saved failures remain unchanged.

**Correction design:** isolate caption judgment from image classification. The comparison model returns NO_CLAIM, UNVERIFIABLE, SUPPORTED or CONTRADICTED plus a reason. The first two map to null, the others to true and false. This is a declared output representation, not a Python keyword classifier. A reason is required for inconclusive states. The final record retains the original visual answer and comparison output; only the comparison fields are composed. If no text exists, the second call is skipped. Visual confidence is not a calibrated confidence in the caption decision.

**Runtime distinction:** the first-stage observation schema is unchanged. The second stage has an enum schema and adds an inference call. This is a configuration comparison of a chain, not evidence that prompt wording alone caused a gain. Both stages use the same installed model and decoding settings.

**Evaluation and limits:** [protocol](../../evaluation/vision/text_chain/protocol.md), same six development conditions and explicitly reused v6 controls. The known `3awnouna` caption appears in an example, so this tests a targeted correction. The comparison stage cannot repair incorrect visual observations or infer a hidden leak. No broader category, rejection or language accuracy is established.

**Measured outcome:** 5/6 comparison targets, 2/2 vague cases explained, 6/6 categories and severities; eleven calls across six pipelines. T04 wrongly received CONTRADICTED because the first pass omitted branches and the reviewer treated that omission as a conflict. V9 was not promoted. See [metrics](../../evaluation/vision/text_chain/metrics.json) and [individual reviews](../../evaluation/vision/text_chain/review.csv).
