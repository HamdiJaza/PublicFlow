# Vision v8: text-only comparison examples

**Executable prompt:** [v8.txt](v8.txt). The exact v6 instructions are retained, followed by three short caption/target examples.

**Role:** classify the current photograph and distinguish supported, contradicted and non-checkable text.

**Techniques and comments:** role prompting, fixed labels, structured-output instructions, explicit comparison criteria, visual grounding and abstention guardrails from v6; text-only few-shot examples contrast null/true/false. The first example explains the known Tunisian caption `3awnouna` as a help request. The other examples use reviewed facts from the separate real IMG-02 photo, without sending that photograph or a full description/evidence answer. Targets are authored demonstrations, not model results. Examples are restricted to the comparison fields to reduce copying of visual answers.

**Observed failures motivating the change:** v6 still accepted both vague requests and the contradictory claim (3/6 comparisons). V7 reached 5/6, but called `3awnouna` false, copied bags/boxes from IMG-02 into IMG-01 and overestimated road severity.

**Evaluation:** [fixed protocol](../../evaluation/vision/text_examples/protocol.md), six new calls using the same cases, model, schema, rubric, validation and decoding parameters, compared with six explicitly reused v6 controls. No code translates or rewrites the model response. V6/v8 tests adding these particular examples and clarification; v7/v8 changes the demonstration format and is a configuration comparison.

**Limit:** the known caption appears literally in this prompt. Success on it is a targeted regression correction, not independent evidence of Tunisian-language understanding. All cases were used during development. No wider category, blur or rejection improvement is claimed from these six cases.

**Measured outcome:** 4/6 comparison targets, 0/2 vague cases with null plus reason, 6/6 categories and 5/6 severities. Both vague requests still received true; T01 had null severity; T05 got the correct false flag but repeated the contradictory citizen text in its visual evidence. V8 was not promoted. [Metrics](../../evaluation/vision/text_examples/metrics.json) and [per-case review](../../evaluation/vision/text_examples/review.csv) preserve the failure. The next tested correction is the [v9 chain](v9.md).
