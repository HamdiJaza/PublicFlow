# Vision v1

**Executable prompt:** [v1.txt](v1.txt). **Role:** classify a municipal photograph and optional description into the fixed output contract.

**Techniques:** zero-shot (no examples), role prompting (municipal photo analysis), fixed category labels, requested JSON fields, visual evidence and uncertainty/location guardrails. JSON schema enforcement is an additional runtime constraint.

**Observed failures:** baseline responses used a bin's presence or absence of other incident types as supporting waste evidence. In the paired study both v1 and v2 omitted water on IMG-04. Early Qwen3-VL empty outputs were model/runtime failures, not proof that the prompt alone failed.

**Correction:** [v2](v2.md) asks for direct issue observations, excludes irrelevant negatives and distinguishes visible water from a confirmed leak source. On IMG-01 its evidence improved, but irrelevant uncertainty remained. The wet-road omission was not fixed.

**Before/after evidence:** [20261011T213841Z review](../../evaluation/vision/comparisons/20261011T213841Z/review.csv), [full analysis](../../docs/research/vision_prompt_evaluation.md).

**Comment:** v1 already included JSON, NONE and evidence. Its actual history is retained even though the team guide suggested introducing those features in later versions.
