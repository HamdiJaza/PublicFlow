# Vision v3

**Executable specification:** [v3.json](v3.json), using the exact [v2 system prompt](v2.txt).

**Role:** classify the query after three real image/answer demonstrations: waste (IMG-02), road damage (IMG-06), uncertain utility equipment (IMG-10).

**Techniques:** multimodal few-shot prompting plus the same role, fixed labels, JSON and evidence/uncertainty rules as v2. The three image/answer pairs are in the actual message history. Annotation comments are not sent. Query-scene overlap with demonstrations is rejected before inference.

**Observed failures:** copied uncertainty text and an unsupported pile of waste on the wet-road image in the first paired trial. Null severity/confidence in the examples influenced outputs but did not establish calibration.

**Correction attempted:** v4 removed demonstrations and used an explicit checklist; its six-scene comparison still omitted water and misread walls/equipment as waste. V5 separated observation and classification; later schema corrections fixed structural failures, but visual and category/evidence errors remained. These are documented failed attempts, not guaranteed fixes.

**Evidence:** [v2/v3 review](../../evaluation/vision/comparisons/20261017T104705_090963Z/review.csv), [v4/v5 library](prompt_library.md), [final controlled comparison](../../evaluation/vision/final_study/metrics.json).

**Comment:** the final study retains these examples unchanged, including null demonstration severity, and applies the same severity rubric to both compared system prompts.

**Final outcome:** 11/11 validated outputs; 4/5 clear-reference categories; 3/4 conservative abstentions; 0/4 severity matches and 0/2 text comparisons. The blurred case returned null but invented a facade/window/door. Both text conditions copied null consistency. These results support selected abstention improvements while exposing evidence and example-imitation failures.
