# Vision v6: explicit text/image comparison

**Executable prompt:** [v6.txt](v6.txt). **Role:** classify the visible municipal issue and compare only checkable claims in the supplied description.

**Techniques:** zero-shot role prompting, structured-output instructions, fixed labels, explicit decision criteria, visual grounding and abstention guardrails. The observable-claim check is an instruction inside one call. There are no demonstrations, extra model calls, chain-of-thought transcripts or trained weights.

**Observed failure:** the [actual submitted request](../../evaluation/vision/runs/20261017T174532_118741Z_UPLOAD-3a42ff6ad5fd.json) supplied IMG-01 with `3awnouna`. V2 returned WASTE/MEDIUM, consistency true, confidence 0.9 and null uncertainty. The photograph supports waste, but a vague request supplies no observable claim to verify. Its evidence also underdescribed the dominant vegetation.

**Correction proposed:** true requires a supported visual claim; false requires a direct contradiction; null covers absent, vague, unverifiable or not-understood text. Supplied text with null comparison needs an explanation. Uncertainty can concern the image or the text. Describe dominant visible material independently of the caption. No caption keyword list or length cutoff is used.

**Runtime distinction:** a common post-validation rule requires a nonblank reason for inconclusive supplied-text comparisons. It applies equally to v2 and v6. Python does not determine semantic agreement or rewrite the generated answer. The seven-field JSON schema remains unchanged.

**Before/after evidence:** [predeclared protocol](../../evaluation/vision/text_comparison/protocol.md), [fixed cases](../../evaluation/vision/text_comparison/cases.json), [run index](../../evaluation/vision/text_comparison/runs.jsonl). Six conditions compare v2/v6 with identical model, schema, rubric and options. The endpoint changes only if the declared comparison and visual-review gates pass. The measured outcome belongs in [metrics](../../evaluation/vision/text_comparison/metrics.json) and [review](../../evaluation/vision/text_comparison/review.csv).

**Comment:** the exact triggering caption does not appear in v6. Generic decision rules must handle it. The study measures a complete instruction revision and cannot attribute any improvement to one sentence alone. Two scenes and authored descriptions do not establish broad language understanding.

**Observed outcome:** v2 and v6 both matched 3/6 text references and neither handled either vague request correctly. V6 also missed one severity reference. Twelve outputs were structurally valid, but the main semantic failure remained. V6 was not promoted. The next revision, [v7](v7.md), tests contrasting image/caption demonstrations with these same instructions.
