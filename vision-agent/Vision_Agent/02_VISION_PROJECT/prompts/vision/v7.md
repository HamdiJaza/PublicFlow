# Vision v7: contrastive image/text examples

**Executable specification:** [v7.json](v7.json), with the exact [v6 system instructions](v6.txt).

**Failure motivating this version:** v6's explicit criteria still returned true consistency on the actual vague caption and on the vague English request. More instructions alone did not demonstrate the intended correction.

**Role and techniques:** multimodal few-shot prompting with contrastive captions on a real demonstration image; the same role, schema, comparison criteria, grounding and abstention rules as v6. This is one model call, not prompt chaining or a reasoning transcript.

**Demonstrations:** IMG-02 contains bags, boxes and loose rubbish around a container. Three authored caption/answer targets demonstrate null for a request without a visual claim, true for supported content, and false for denial of visible rubbish. They are reference annotations, not fabricated model responses. The query scenes cannot overlap this demonstration scene. Exact test captions are absent from the examples.

**Evaluation:** [protocol](../../evaluation/vision/text_few_shot/protocol.md). Six new v7 calls are compared with the six saved v6 controls under identical parameters, schema and query inputs. System-prompt hashes must match; demonstrations are the only message-history change. Reused controls do not provide an interleaved speed benchmark. All failed attempts remain recorded.

**Comment:** the earlier v3 examples all used null consistency and did not demonstrate agreement versus contradiction. V7 supplies those missing contrasting targets. Whether that improves the measured cases must be established from actual outputs, not inferred from the technique name.

**Measured outcome:** 5/6 comparison targets, 1/2 vague cases with null and an explanation, 6/6 categories and 5/6 severities. The actual `3awnouna` caption received false even though the explanation admitted there was no scene claim. Four IMG-01 outputs copied the demonstration's bags/boxes description instead of identifying the dominant branches; the no-text case invented a submitted assistance request. The road case was assigned HIGH rather than MEDIUM. V7 was not promoted. See [metrics](../../evaluation/vision/text_few_shot/metrics.json) and [individual reviews](../../evaluation/vision/text_few_shot/review.csv).

**Next correction:** [v8](v8.md) removes example photographs and complete visual answers, testing short text-only comparison examples instead. It explicitly explains the known triggering caption; this is development regression work, not held-out language evaluation.
